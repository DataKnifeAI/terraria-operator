Built for hosting a world

Not a launcher — an operator that stands up the dedicated server your players join.

  • Declare × Reconcile

    Apply a CR. The controller builds StatefulSet, PVC, Services, and an Envoy Gateway TCPRoute on 7777.

  • Images × Licenses

    We never redistribute Terraria or TShock. Default image is ghcr.io/pryaxis/tshock:stable.

  • Versions × Drift

    Clients auto-update; servers chase. Status surfaces TShock release vs installed Terraria compat.

How it works

Three steps from CRD to a running world.

  1. Install the operator

    make install then make deploy — CRDs, RBAC, and controller land in your cluster.

  2. Declare a TerrariaServer

    Pick world size/difficulty, pin or track stable, set a Gateway VIP. TShock REST stays ClusterIP-only.

  3. Share the address

    Read status.connectionAddress and status.connectionPort (TCP 7777), then Multiplayer → Join via IP.

Connect from Terraria

Once the CR is Ready, players join from the game client — not from kubectl. See docs/TERRARIA_SERVER.md.

1. Read the address (admins)

kubectl get terrariaservers -o wide
# ADDRESS + PORT → status.connectionAddress / connectionPort

kubectl get terrariaserver main -n game-servers \
  -o jsonpath='{.status.connectionAddress}:{.status.connectionPort}{"\n"}'

Share connectionAddress:connectionPort (default port 7777 TCP).

2. Join via IP

  1. Launch Terraria → Multiplayer.
  2. Join via IP → enter the VIP and port from status.
  3. Use the optional game password if access.passwordSecretRef is set.
  • Game 7777 / TCP (Gateway TCPRoute)
  • REST 7878 / TCP ClusterIP-only (TShock admin; never public by default)
  • Default image ghcr.io/pryaxis/tshock:stable

FAQ

Do you ship Terraria or TShock binaries?

No. The operator consumes published images. Terraria dedicated server is a free Re-Logic download; TShock is GPL-3.0 (Pryaxis).

Why is version drift a headline feature?

Terraria clients auto-update; each TShock release targets a specific Terraria build. The compat watcher polls GitHub releases and sets status.updateAvailable.

Is the REST API exposed publicly?

No by default. Port 7878 stays on the ClusterIP Service. Server Manager (Phase 3) proxies it; tokens never leave Secret handling casually.

Where are the rest of the docs?

TERRARIA_SERVER.md, ARCHITECTURE.md, and GITLAB_MIRROR.md live under docs/ (same paths on GitHub Pages).
